## PixelLineage Vault（保管庫）とは？なぜ重要なのか

本質的に、**pixellineage vault**は一時的なキャラクターの挑戦（ラン）とアカウント全体の永続的な進行状況を橋渡しするために設計された、キャラクター共有ストレージです。プレイヤーの個人バックパックは環境の危険、所持枠の制限、デスペナルティの影響を受けますが、保管庫の施設内に安全に預けられたアイテムは一切失われることがありません。

血統システムを採用したゲームでは、キャラクターは歳を取り、戦死し、あるいは引退します。操作中の冒険者が戦闘で倒れると、所持していたアイテムは選択した難易度に応じて地面にドロップするか、破損するか、あるいは完全に失われます。永続的な保管庫インフラはこのリスクを回避し、予備の装備、上位の鍛冶用鉱石、家系のパッシブアイテムなどを安全に蓄えておくための信頼できる場所を提供します。

一時的なインベントリと永続ストレージの違いを理解することは、長期的な攻略計画を立てる上で欠かせません。以下の比較表で、バックパックと保管庫の仕様の違いを確認しておきましょう。

| 機能 / 項目 | 個人用バックパック | PixelLineage Vault（保管庫） |
| :--- | :--- | :--- |
| **死亡時の永続性** | ロスト、または地面にドロップ | 100%保護・安全に維持 |
| **アクセス場所** | いつでも・どこでも利用可能 | 指定の拠点街や聖域のみ |
| **容量タイプ** | 重量制限 / 可変スロット | ティア制の固定スロットグリッド |
| **キャラ間共有** | 不可（現在のキャラ限定） | 可能（アカウントまたは家系全体） |
| **拡張メカニズム** | ポーチ拡張 / 筋力ステータス | ゴールド、アップグレードトークン、勢力名声 |
| **保管制限** | 一時アイテムや呪われたアイテムも所持可 | クエスト専用品や腐敗・消費期限アイテムは預託不可 |

危険地帯に突入する前に主要な装備を保管庫へ預けておくことで、プレイヤーはハイリスクなダンジョン探索を一か八かの賭けではなく、事前の「偵察任務」として割り切って挑むことができます。

## 保管容量の解放とアップグレード方法

拠点となる街で初期の保管スペースを解放すること自体は簡単ですが、容量を拡張していくには計画的なリソース管理が必要です。ゲーム開始時の初期保管庫は数スロット程度しかなく、予備の武器セットとポーション一式を入れるのがやっとの容量です。

より高いティアを解放するには、主要都市にいる専用の保管庫番NPC（Storage Keeper）を見つける必要があります。レトロRPGに関する[Steam Community](https://steamcommunity.com/)ハブで共有されているプレイヤーの経験談によると、初期資金を一時的な武器バフに注ぎ込むよりも、早い段階で保管庫の拡張に投資したプレイヤーの方が、中盤以降の攻略を圧倒的にスムーズに進められています。

保管庫のアップグレードには、所持金、進行バッジ、特定の街での名声などに基づいた明確なマイルストーンが存在します。

| 保管庫ティア | スロット数 | 必要コスト | 前提条件・マイルストーン | 推奨進行度 |
| :--- | :--- | :--- | :--- | :--- |
| **Tier 1 (基本)** | 10スロット | 無料 / チュートリアルクエスト | 最初の主要拠点に到達 | 序盤（レベル1～10） |
| **Tier 2 (補強)** | 25スロット | 2,500ゴールド + 鉄のインゴット | 森林ダンジョンのボス撃破 | 序盤〜中盤 |
| **Tier 3 (拡張)** | 50スロット | 10,000ゴールド + 銀の留め具 | 水没した遺跡をクリア | 中盤（レベル25～40） |
| **Tier 4 (付呪)** | 75スロット | 35,000ゴールド + アーケインコア | 街の名声ランク3到達 | 終盤（レベル45～60） |
| **Tier 5 (血統の主)** | 100スロット | 100,000ゴールド + 虚無のエッセンス | ワールドボス / エルダードラゴン撃破 | エンドゲーム / 引退直前 |

### 保管庫ティア解放の重要ステップ

1. **初期拠点のクエストをクリアする：** 第一の拠点で銀行NPCまたは補給係に話しかけましょう。多くのゲームでは、預託ボックスを利用可能にする前に住民権を確認するための簡単な配達クエストが発生します。
2. **精錬済み金属を蓄えておく：** 序盤で手に入れたインゴットを生のまま売却してはいけません。保管庫の拡張には通貨だけでなく、建材となる加工素材がほぼ必ず要求されます。
3. **アップグレード費用を事前に予算化する：** 次のダンジョンで失うかもしれない贅沢な装備にゴールドを散財する前に、獲得した懸賞金や報酬の20%を保管庫の拡張資金としてプールしておきましょう。

保管庫が拡張されれば、**pixellineage vault**に様々な特化ビルド用の装備をストックできるようになり、次のキャラクターを育成する際にも最初から最適化された装備構成ですぐにスタートできます。

## 優先すべき保管アイテム：スタッシュマトリクス

特に終盤のストレージティアに達する前は、スロット数は限られています。商人から簡単に購入できる低価値の消費アイテムや通常装備を溜め込んでしまうのはよくある失敗です。**pixellineage vault**を効率的に運用するには、アイテムの希少性、実用性、そして再入手の難易度に基づいた厳格な優先順位付けが不可欠です。

アイテムは基本的に「最優先（Critical）」「状況依存（Situational）」「使い捨て・処分（Disposable）」の3つのレベルに分類して管理します。

| 優先度レベル | アイテムカテゴリ | 具体例 | 保管庫に預けるべき理由 |
| :--- | :--- | :--- | :--- |
| **優先度A（最優先）** | 家系の遺産（Heirloom）＆アーティファクト | 魂縛の剣、伝説の指輪 | 代替が利かず、新規ランの戦力を即座に底上げできるため |
| **優先度A（最優先）** | 希少な精錬・強化素材 | アダマンタイト、ドラゴンの鱗、秘術のルーン | ドロップ率が極めて低く、終盤のクラフトに不可欠なため |
| **優先度B（状況依存）** | 属性耐性装備セット | 耐火の鎧、毒耐性の指輪 | 特定のボス戦や過酷な環境バイオームの攻略に必須なため |
| **優先度B（状況依存）** | バックアップ用レベリング装備 | +3強化の育成用武器、標準的な重装プレート | 不意の全滅（ワイプ）から素早く立て直すために必要なため |
| **優先度C（保管不要）** | 一般ドロップ品＆基本消費アイテム | 下級回復薬、ゴブリンのダガー | 安価で購入可能であり、貴重な保管スロットを圧迫するため |

### クラフト触媒・素材の管理

クラフト触媒や鉱石素材は、スロットあたりの価値がゲーム内で最も高いアイテムです。通常の武器とは異なり耐久度の低下がなく、多くの場合99個や999個までスタックできます。探索バッグが希少な鉱石でいっぱいになったら、より危険な深層バイオームへ進む前に一度拠点へ戻り、**pixellineage vault**に預託する習慣をつけましょう。

## 継承メカニズムとデスペナルティの軽減策

永続保管庫を活用する最大の理由は、キャラクター死亡時の損失軽減です。血統継承を備えたゲームでは、個々のキャラクターは一時的な「器」にすぎず、家系そのものがアカウント全体のマクロな成長記録を表しています。

プレイ中のキャラクターが死亡した場合、インベントリ内の所持品は難易度設定に基づいた一般的な死亡ルールによって処理されます。以下の表は、リネージュ系RPGでよく見られる死亡時のリスク設定です。

| ゲームモード | 死亡時の損失（バックパック内） | 死亡時の損失（保管庫内） | 最善の戦略 |
| :--- | :--- | :--- | :--- |
| **カジュアル / ノーマル** | 所持金の10%消失、装備の耐久度低下 | 損失0% | 予備ビルド用の装備や余剰資金の保管に利用する |
| **ハードコア / アイアン** | 全アイテムの完全ロスト、キャラクターロスト | 損失0%（次の継承者へ引き継ぎ） | ボス戦の前に不要なアイテムをすべて預けておく |
| **シーズン / イベント** | 回収タイマー付きで地面にドロップ | 損失0%（シーズン専用スタッシュに固定） | 緊急脱出用スクロールを保管庫に常備しておく |

### 安全地帯での保管ルーティン

規則正しいアイテム預託の習慣を身につけることで、未然に防げる装備ロストのストレスを解消できます。熟練プレイヤーは多くの場合、「2つのルール（Rule of Two）」を実践しています。

* **1つは手元に、1つは保管庫へ（Keep One, Bank One）：** 高性能な装備の重複（スペア）を入手した際は、目先の小銭のために売却するのではなく、すぐに2つ目を**pixellineage vault**へ預けましょう。
* **ダンジョン突入前の荷物整理（Pre-Dungeon Purge）：** 未踏のダンジョンに足を踏み入れる前に、必須ではないユーティリティアイテムをバックパックからすべて取り出します。その回の探索で実際に使い切る予定のポーション、矢、道具類だけを持ち歩くようにしてください。
* **遺産の事前退避（Heirloom Caching）：** キャラクターが引退年齢に達した際や、高難度ボスの素材回収を目的とした特攻（捨て身のラン）を行う場合は、事前に先祖伝来のレリック・遺産装備をすべて外し、保管庫に格納しておきましょう。

アイテムを預ける行為のひとつひとつをアカウントの次世代への「投資」と捉えることで、過酷な全滅に見舞われても揺るがない盤石の武器庫を築き上げることができます。

## よくある保管庫・スタッシュのエラーと解決策

保管庫システムは基本的に堅牢に作られていますが、アイテム整理中に不具合やUIトラブルに直面することがあります。コミュニティからは、インベントリの非同期、スロットのロック、あるいは特定の進行状態においてアイテムが取り出せなくなるといった報告が寄せられています。

保管庫メニューで不具合が発生した場合は、以下の対処法を試してみてください。

* **アイテムがグレーアウトしている：** 未完了のアクティブなサイドクエストに関連付けられているアイテムは預けることができません。クエストをクリアするか破棄してから預け直してください。
* **スロット拡張が反映されないバグ：** 購入後に拡張スロットが視覚的に反映されない場合は、現地の宿屋でセーブし、タイトル画面に戻ってからゾーンを再読み込みするとグリッドが正常に更新されます。
* **キャラ間でアイテムが見えない制限：** 別のキャラクターで前のキャラクターが預けたアイテムが確認できない場合、両方のキャラクターが同一のワールドレルムおよび家系に属しているか確認してください。ハードコアと通常キャラでは保管庫プールが完全に分離されています。

保管庫を定期的に整理し、列ごとにアイテム種別を分けておくことで、紛失に素早く気づけるだけでなく、将来のクラフトに必要な素材数も把握しやすくなります。

## よくある質問（FAQ）

### キャラクターが死亡した場合、pixellineage vault内のアイテムは失われますか？
いいえ。永続保管庫に預けられたアイテムは、キャラクターの死亡、状態異常、ゲームオーバー画面の有無にかかわらず、完全に保護されます。死亡時のドロップペナルティの対象となるのは、冒険者が個人バッグに入れて持ち歩いていたアイテムのみです。

### 保管庫のスロット総数を増やすにはどうすればよいですか？
主要都市にいる銀行NPCや保管庫番NPCに話しかけることで拡張できます。アップグレードには、ゴールド、鉄や銀などの精錬建材、特定の実績進行や街の名声ランクが必要になります。

### 保管庫内のアイテムはすべてのキャラクター間で共有されますか？
はい。同じ家系クラスターおよび同じゲームモードに属しているキャラクター同士であれば共有されます。通常モードのキャラクターは同じ中央保管庫を共有できますが、ハードコアやシーズンのキャラクターはゲームバランス維持のため、独立した専用の保管庫プールを使用します。

### 保管庫に預けるのを避けるべきアイテムは何ですか？
基本的な木の矢、下級回復ポーション、一般的な雑魚敵のドロップ品など、簡単に買い直せるアイテムの保管は避けてください。限られたスロット容量は、希少なクラフト素材、上位の防具セット、次の世代が必要とする代替不可能な遺産アーティファクトのために温存しておきましょう。
