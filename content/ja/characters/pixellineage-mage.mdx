## PixelLineage メイジの基本概要

PixelLineageにおけるメイジは、典型的な「ガラスの砲台（高火力・紙防御）」の役割を担います。重装プレートアーマーと防御スキルに依存する前衛の守護者たちとは異なり、術者は瞬間火力（バースト）、クラウドコントロール（CC）、そして回避のための立ち回りのみに身を委ねます。

```
[素の知力] + [マナ自動回復] ➔ 最大の呪文瞬間火力 ＆ 持続DPS
[ポジショニング ＆ カイト] ➔ 被ダメージ軽減 ＆ 生存性向上
```

コミュニティの報告でも頻繁に指摘されている通り、アーケイン術者のプレイは序盤の難易度（学習曲線）が高いものの、終盤の育成におけるスケーリングの爆発力は他のほぼあらゆる攻撃型クラスを凌駕します。

### 主な強みと固有の弱点

スキルポイントを割り振る前に、このクラスメカニクスに組み込まれている根本的な長所・短所を理解しておくことが不可欠です。

| 特徴カテゴリー | 固有の長所 | クラスの短所・限界 |
| :--- | :--- | :--- |
| **ダメージ特性** | 高い属性瞬間火力、画面全体を覆う広範囲AoE | 物理ダメージ皆無、マナプールへの極端な依存 |
| **防御レイヤー** | アルケインシールド、瞬間テレポート、行動妨害CC | 布装備（ローブ）のみ着用可、極めて低い基礎体力 |
| **グループ貢献度** | 敵への属性デバフ付与、味方へのマナ回復付与 | 敵のヘイト（ヘイトスパイク）や沈黙状態異常に脆弱 |
| **ソロ適性** | 効率的な雑魚殲滅能力、エリート敵へのカイト能力 | 追い詰められた際やクールダウン中の立て直しが困難 |
| **経済・コスト** | 完成後の圧倒的なファーム（周回）速度 | 序盤におけるマナポーションや触媒への出費が激しい |

## 推奨ステータス優先度とキャラクター割り振り

キャラクターに投資するステータスポイントの1つ1つが、バトルの快適さを左右します。**pixellineage mage**における最優先スケーリングステータスは「知力（Intelligence）」であり、それに僅差で「知恵（Wisdom）」（マナ回復およびクールダウンの回転効率）と「体力（Constitution）」（ボスのギミックによる即死防止）が続きます。

```
最優先: 知力（ダメージ / 呪文クリティカル）
第2優先: 知恵（最大マナ容量 / リソース自動回復）
第3優先: 体力（最大HPライン / 属性耐性）
```

ソロでの雑魚狩りを重視するか、連携の取れたダンジョンレイドを重視するかによって、ポイント配分は異なります。

### 最適なステータス配分テンプレート

属性ポイントをすべてのステータスに中途半端に分散させると、瞬間火力が低下してしまうことがプレイヤーの実績から実証されています。ビルドを構築する際は、以下の検証済みベンチマークを参考にしてください。

| ビルドテンプレート | 知力重視 | 知恵重視 | 体力重視 | 推奨プレイスタイル |
| :--- | :--- | :--- | :--- | :--- |
| **純粋エレメンタリスト** | 70% | 20% | 10% | 連携の取れたダンジョングループ、最大バーストDPS |
| **バトルメイジ / ソロ** | 55% | 25% | 20% | ソロ周回、危険度の高いフィールド探索 |
| **アルケインコントローラー** | 50% | 35% | 15% | PvP戦闘、持続的なCCとユーティリティ支援 |
| **クリティカルバースト特化** | 75% | 15% | 10% | ボスTA（タイムアタック）、エンドゲーム最高峰装備用 |

### 目指すべき重要ステータスマイルストーン

*   **初期マナ上限:** マナ回復のために足を止めることなく、基本の呪文ローテーションを連続で3巡撃ち切れるだけの基礎マナ量を確保しましょう。
*   **詠唱速度のソフトキャップ:** 詠唱時間短縮によってシームレスなモーションキャンセルが可能になったら、余剰ポイントは純粋な呪文威力（スペルパワー）に再投資します。
*   **有効ヘルスバッファー:** 体力への投資を完全に怠ってはなりません。通常のダンジョン雑魚敵による不意の一撃を最低でも1回は耐えられる耐久力が必要です。

### 序盤のアビリティ習得手順

初期レベル帯では、主力となる遠距離単体火力スキルと、確実に距離を取れる離脱スキルを最優先で解放しましょう。

*   **ステップ1:** 単体投射スキルを最大まで強化し、基本的な野生モンスターや初期ダンジョンの見張りを効率よく処理できるようにします。
*   **ステップ2:** 地面凍結または移動速度低下スキルを即座に解放します。被ダメージを回復するよりも、そもそも攻撃を受けない立ち回りの方が圧倒的に優れています。
*   **ステップ3:** 危険な敵が徘徊するレベリングエリアに足を踏み入れる前に、最初のユーティリティポイントをブリンク（瞬間移動）または防御シールドに投資します。

### 終盤の呪文コンボ

呪文ツリーが広がり充実してきたら、アビリティを組み合わせてダメージを爆発的に跳ね上げましょう。

1.  **フリーズ・シャッターコンボ:** 範囲足止めスキルで迫り来る敵グループを縫い留め、すかさず貫通型のアイスランスを撃ち込んで確定クリティカルを叩き込み、生き残った敵を高速のチェインライトニングで一掃します。
2.  **メテオアンブッシュ:** エリートモンスターが戦闘範囲に入る直前に地面へ炎の持続ダメージエリアを設置し、前衛の味方の背後に身を隠しながら最大のDoT（継続ダメージ）を与え続けます。

**pixellineage mage**の育成過程には、明確なパワースパイク（急激に強くなるタイミング）が存在します。序盤のレベル帯は慎重な立ち回りが求められますが、AoEスキルセットが揃った瞬間から、敵を狩る速度は全クラス屈指のものへと進化します。

### 上級者向け戦闘＆カイト（引き撃ち）戦術

**pixellineage mage**として危険な敵の大群と戦う際は、適切なポジショニングの徹底が生命線となります。

*   **最大射程の維持:** 絶対にゼロ距離からローテーションを開始してはなりません。常に最も射程の長い呪文の限界距離から戦闘を開始してください。
*   **円形カイトパターン:** 複数の敵をトレイン（引き連れ）する際は、一直線に後退するのではなく、円を描くように誘導しましょう。これにより敵が一箇所に密集し、範囲攻撃の巻き込み効率が最大化されます。
*   **リソース管理の徹底:** ダメージを出すためだけにマナバーを完全に使い果たしてはなりません。防御シールドや離脱スキルを使用するための緊急用マナを常に一定量温存しておきましょう。

## よくある質問（FAQ）

### PixelLineageのメイジは初心者向けですか？
立ち位置の管理やマナのやりくりに細心の注意を払う必要がありますが、圧倒的な射程の長さがあるため、慎重にプレイできる人なら遊びやすいクラスです。カイトの基本と呪文のローテーションさえマスターしてしまえば、通常のコンテンツ攻略は驚くほど効率的になります。

### PixelLineageメイジで最も効果的なソロビルドは何ですか？
ソロプレイにおいては、多くのプレイヤーが「氷・雷ハイブリッドビルド」を推奨しています。氷系統が信頼性の高いCCとスロウ効果を提供し、雷系統が重い炎呪文のような長い詠唱なしに素早い瞬間火力を叩き出せるためです。

### 序盤の深刻なマナ不足はどうやって克服すべきですか？
序盤のマナ不足を解消するには、サブステータスを「知恵」に振り、敵討伐時マナ回復やマナ自動回復が付いた装備を優先しましょう。また、瀕死の雑魚敵を仕留める際には余計な呪文を撃たず、ワンドの通常攻撃で処理する癖をつけることが重要です。

### メイジと最も相性の良いサブ職業は何ですか？
「錬金術（Alchemy）」と「付呪（Enchanting）」がトップクラスの選択肢です。錬金術は必須となるマナポーションや呪文威力を高める秘薬を自給自足でき、付呪は装備に不可欠なクールダウン短縮や魔法貫通ボーナスを自在に付与できます。
